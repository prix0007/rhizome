RHIZOME

A live 3D map of every device on your local network. One small program, opened in your browser. Nothing leaves your machine.

Run it

tar -xzf rhizome-*.tar.gz
cd rhizome-*
./rhizome

Then open http://127.0.0.1:7878 in your browser.

  • macOS: the binary is not notarised. If macOS blocks it, run xattr -d com.apple.quarantine ./rhizome, and allow Local Network access for your terminal when asked.
  • Windows: unzip, then run rhizome.exe from a terminal.
  • From source: cargo run --release with a recent Rust toolchain.

What it does

  • Finds devices on your subnet and shows vendor, name and type where they can be learned.
  • Updates live as devices join and leave, and remembers when each was first and last seen.
  • Listens on 127.0.0.1 only. No cloud service, no account, no telemetry.

Only scan networks you own or are allowed to scan.
